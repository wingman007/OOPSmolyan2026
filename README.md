# OOPSmolyan2026

A simple C# console project demonstrating object-oriented programming concepts such as:
- classes and objects (`Person`, `Student`, `Athlete`)
- interfaces (`IIntroducable`)
- inheritance and polymorphism

## Requirements
- .NET SDK 10.0+

## Build
```bash
dotnet build
```

## Run
```bash
dotnet run --project OOPSmolyan2026/OOPSmolyan2026.csproj
```

## Test
```bash
dotnet test
```
